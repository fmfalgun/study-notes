# practice/

SQLite-backed practice-question server for ISRO exam prep. Serves small
batches of real questions instead of a full list, and tracks per-question
outcomes so future batches adapt to your progress.

## Files

- `schema.sql` — DB schema: `questions` (one row per real question, sourced
  from `topics/isro-prev-attempt-1/`) and `attempts` (one row per time you
  answer a question).
- `practice.py` — CLI: `init`, `next`, `answer`, `stats`, `hint`, `link`, `explain`.
- `ai_explain.py` — shells out to the `claude` CLI (`claude -p`, one-shot,
  Haiku model, no tools) to generate a short explanation for a question when
  the stored hints aren't enough. Runs under whatever account is logged in
  to Claude Code, so it's billed the same as any other usage of the CLI —
  no separate API key or charge.
- `load_json.py` — bulk-loads a JSON array of question objects into
  `questions` (used once to seed the DB from the transcribed exam paper).
- `practice.db` — gitignored, generated by `init` + `load_json.py`.

## Workflow

```
python3 practice.py init                      # create practice.db (idempotent)
python3 practice.py next                      # get 3 questions, picked by your weakest areas
python3 practice.py next --n 2 --topic OS      # narrower batch
python3 practice.py answer 17 c                # auto-graded against the known correct answer
python3 practice.py answer 17 correct          # self-report, if no correct_answer is on file
python3 practice.py answer 17 hint             # you needed a hint
python3 practice.py answer 17 skip             # you skipped it
python3 practice.py stats                      # per-topic progress, from attempts table
python3 practice.py stats --topic OS
python3 practice.py hint 59 --level 2          # show hints 1..2 for a question
python3 practice.py link 59                    # topic reference link, if one is on file
python3 practice.py explain 59                 # AI explanation (cached after first call)
python3 practice.py explain 59 --refresh       # regenerate instead of using the cache
```

In the interactive TUI, press `e` on a question to get the same explanation
inline — cached ones show instantly, uncached ones take a few seconds while
`claude` is queried.

`next` never dumps the whole bank — it ranks questions by last outcome
(wrong/never-tried first, solved-cold last), then tier, then difficulty, then
attempt count, and returns the top `--n` (default 3).

## Data notes

95 questions total, transcribed from the previous attempt paper (Set C).
7 are marked `answer_status = 'unverified'` (genuine ambiguity between two
options) — `answer` will refuse to auto-grade these and ask you to
self-report with `correct`/`incorrect` instead.
