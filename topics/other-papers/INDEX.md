## Notes
- SAC and VSSC run their own center-level recruitment; ICRB (ISRO Centralised Recruitment
  Board) papers are for the HQ-level pooled Scientist/Engineer 'SC' recruitment shared
  across centers — same official CS syllabus, worth mining for topic coverage even though
  it's a different hiring track than SAC's own.
- Two files are answer-key-only (no question text) — useful for confirming topic tags per
  question number if a companion question paper for that same test date turns up, but not
  usable standalone for question-paper analysis.
- Third-party aggregators (Testbook, Adda247, GeeksforGeeks, PracticePaper.in, Cracku, a
  GitHub repo by ardraslal) surface the same SAC 2020/2023 papers already grabbed directly
  from sac.gov.in — no new content found there beyond what's listed above.
