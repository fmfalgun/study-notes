# subjects/

Shared, track-agnostic CS-fundamentals notes — one file per subject. These aren't scoped to any
single exam; both `../tracks/isro/` and `../tracks/gate/` draw on the same underlying CS syllabus,
so the notes live here once instead of being duplicated per track.

`math-crossover-analysis.md` and `calculus-made-easy-book-review.md` are Mathematics-subject
supplementary material (cross-referenced against outside engineering work and a book review,
respectively) — same reasoning for living here rather than under a track.
